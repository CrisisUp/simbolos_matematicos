## 💡 Como Usar

- **Cópia Rápida:** Os símbolos nos blocos de código estão intencionalmente espaçados para facilitar a seleção e cópia individual de qualquer caractere com o mouse.

- **Aplicações Práticas:** Ideal para inserção rápida em arquivos `.md` (Markdown), documentações técnicas, comentários de código (`//`, `#`) e anotações em editores de texto plano (como Bloco de Notas, Obsidian ou VS Code).

- **Modo Raw:** Se preferir copiar blocos inteiros de uma vez, clique no botão **"Raw"** no topo de qualquer arquivo no GitHub para visualizar o texto puro sem formatação.

## 🛠️ Dica Útil: Mapa de Caracteres do Windows (Charmap)

O **charmap** é uma ferramenta nativa excelente para quem trabalha com símbolos e precisa encontrar caracteres Unicode específicos de forma rápida, sem precisar ficar caçando na internet.

Para usá-lo no dia a dia junto com o seu repositório:

### Como abrir e usar o Mapa de Caracteres no Windows

1. Pressione as teclas **`Windows + R`** no seu teclado para abrir a janela *Executar*.
2. Digite **`charmap`** e aperte **`Enter`**.
3. Uma janela compacta será aberta com uma grade de símbolos.

### Dicas úteis de uso

- **Escolha da Fonte:** No campo *Fonte*, você pode selecionar fontes ricas em símbolos matemáticos e técnicos (como *Segoe UI Symbol*, *Cambria Math* ou *Arial*).
- **Busca por Código Unicode:** Se você souber o código do caractere (por exemplo, `221E` para o símbolo de infinito `∞`), basta marcar a caixa **Modo de exibição avançado**, selecionar **U+** no campo "Ir para o Unicode" e digitar o código para achá-lo instantaneamente.
- **Cópia:** Clique duas vezes no símbolo desejado para colocá-lo na barra inferior ("Caracteres a copiar") e clique no botão **Copiar**.

É um atalho prático e direto do sistema operacional para complementar o seu *cheat-sheet* sempre que precisar descobrir um caractere novo!

## 🍏 Dica Útil: Visualizador de Caracteres do Mac (Character Viewer)

No macOS, o equivalente nativo ao mapa de caracteres é o **Visualizador de Caracteres**, um painel gráfico integrado excelente para buscar e inserir qualquer símbolo especial rapidamente.

### Como abrir e usar no Mac

1. Pressione o atalho rápido: **`Control + Command (⌘) + Espaço`** no seu teclado para abrir a janela flutuante de emojis e símbolos.
2. No canto superior direito da janela flutuante, clique no ícone de um **pequeno teclado quadrado** (ou nos comandos de expansão) para abrir o painel completo.

### Dicas úteis de uso no Mac

- **Navegação por Categorias:** Na barra lateral esquerda, explore categorias organizadas como *Símbolos Matemáticos*, *Setas*, *Sinais de Moeda* e o *Alfabeto Grego*.
- **Busca por Nome ou Código:** Use a barra de pesquisa no topo da janela para digitar o nome do caractere (ex: *"alpha"*, *"infinito"*, *"integral"*) ou cole o código Unicode correspondente.
- **Inserção:** Dê um duplo clique no símbolo desejado para inseri-lo diretamente onde o seu cursor estiver posicionado.

## 📖 Guia de Significados (Referência Rápida)

### Geometria e Álgebra

- **`∠`** — Ângulo
- **`°`** — Grau (unidade de medida)
- **`⊥`** — Perpendicularidade
- **`∥`** — Paralelismo
- **`△`** — Triângulo
- **`≅`** — Congruente
- **`∼`** — Semelhante
- **`π`** — Pi (razão da circunferência, $\approx 3,14159$)
- **`∫`** — Integral
- **`∮`** — Integral de linha fechada
- **`√`** — Raiz quadrada
- **`∛`** — Raiz cúbica
- **`∞`** — Infinito

### Significados de Teoria de Conjuntos e Lógica

- **`∈`** — Pertence a
- **`∉`** — Não pertence a
- **`∪`** — União de conjuntos
- **`∩`** — Intersecção de conjuntos
- **`⊂`** — Contido estritamente em (subconjunto próprio)
- **`⊆`** — Contido ou igual a (subconjunto)
- **`∅`** — Conjunto vazio
- **`⇒`** — Implica (condicional)
- **`⇔`** — Se e somente se (bicondicional)
- **`∧`** — E lógico (Conjunção)
- **`∨`** — Ou lógico (Disjunção)
- **`¬`** — Negação lógica (Não)
- **`∀`** — Para todo (Quantificador universal)
- **`∃`** — Existe (Quantificador existencial)
- **`∴`** — Portanto
- **`∵`** — Visto que / Porque

### Estatística, Probabilidade e Inferência

- **`μ`** — Média populacional
- **`σ`** — Desvio padrão populacional
- **`σ²`** — Variância populacional
- **`x̄`** — Média amostral
- **`s`** — Desvio padrão amostral
- **`s²`** — Variância amostral
- **`P(A)`** — Probabilidade do evento A
- **`P(A|B)`** — Probabilidade condicional (A dado B)
- **`E(X)`** — Esperança matemática (Valor esperado)
- **`Var(X)`** — Variância de uma variável aleatória
- **`H₀`** — Hipótese nula
- **`H₁`** — Hipótese alternativa
- **`α`** — Nível de significância (Erro Tipo I)
- **`β`** — Probabilidade de Erro Tipo II
- **`χ²`** — Qui-quadrado
